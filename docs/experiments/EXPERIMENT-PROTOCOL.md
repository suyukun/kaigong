# 实验协议模板（复用框架，v1）

新实验复制本文件为日期-命题.md 的"设计"节骨架，判据部分另出预注册文件（测试开始前冻结）。

1. **命题一句话**（要证伪什么，不是要证明什么）
2. **双臂**：处理组／对照组（同模型、同任务书、同台词；声明共享污染源——L0／技能库）
3. **判据预注册**：每条判据必须机器可查（文件存在性／命令输出／git 历史）；通过线先定
4. **台词固定**：含至少一轮对抗轮（明令违反规范，测制度韧性）
5. **机器取证**：每轮结束后立即 find＋check＋测试实跑，存档输出
6. **归因纪律**：换变量就声明混杂；结论只说到证据支持的粒度
7. **收尾**：git init／commit 钉终态；虫子清单直接转产品 backlog
